Modern Enduro UI Kit

Modernized replacement PNG sprites for Unity UI. Use these for a cleaner premium HUD style with dark glass panels, cyan/green neon accents, soft shadows, and rounded controls.

Unity import suggestions:
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Mesh Type: Full Rect
- Compression: None or High Quality for UI
- For panels/buttons/borders, set Sprite Editor borders and use Image Type = Sliced.
