Modern Enduro UI Kit - Cropped Sprites

Each PNG here is an individual cropped sprite with transparent padding trimmed.
Use this folder when replacing UI Images in Unity.

Suggested Unity import settings:
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Mesh Type: Full Rect
- Compression: None or High Quality
- For panels/buttons/borders: set Sprite Editor borders, then use Image Type = Sliced.
