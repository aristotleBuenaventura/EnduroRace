Enduro UI Generated Kit

PNG sprites with transparent backgrounds for Unity UI replacement.

Suggested Unity import settings:
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Pixels Per Unit: 100
- Mesh Type: Full Rect
- For panels/buttons/borders: use Image Type = Sliced after setting Sprite Editor borders.

Files include panels, buttons, joystick parts, action button frames, minimap bezel, progress bar, warning/start banners, borders, and simple white icon overlays.
